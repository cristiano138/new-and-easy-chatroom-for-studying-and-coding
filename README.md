# 局域网聊天室（LAN ChatRoom）

一个开箱即用的**局域网聊天软件**。在一台电脑上运行服务，同一个局域网（校园网、公司内网、家用 WiFi）里的其他人用浏览器打开网址就能聊天，**不需要联网、不需要公网服务器、不需要装任何客户端**。

后端 Python + FastAPI + WebSocket + SQLite，前端单个 HTML 文件（原生 JavaScript，无框架、无构建工具）。整个项目只有几百行后端代码，适合学习、改造、二次开发。

---

## 一、功能一览

| 功能          | 说明                                                   |
| ----------- | ---------------------------------------------------- |
| 账号注册 / 登录   | 无需邮箱手机号，起个名字设个密码即可。密码用 PBKDF2-SHA256 加盐哈希存储，数据库里没有明文 |
| 记住登录        | 登录一次后，关页面、重启服务都会自动进入（30 天有效），点右上角退出即失效               |
| 公共聊天室实时广播   | 消息秒达，多人同时发送互不干扰                                      |
| 多频道         | 默认「闲聊」「工作」两个频道，各自独立的消息记录和在线成员                        |
| 在线成员列表      | 有人进入 / 离开时实时更新                                       |
| 消息历史持久化     | 存在 SQLite 里，**重启服务、重启电脑消息都不丢**，新人进入能看到历史             |
| 纯文本 + emoji | 支持表情面板；恶意内容（`<script>` 之类）一律按纯文本显示，不会执行              |
| 删除自己的消息     | 只能删自己发的；绕过界面直接调接口也会被服务端拒绝                            |
| 管理员清空频道     | **第一个注册的账号自动成为管理员**，可清空当前频道记录                        |
| 管理员转让       | 管理员可把权限转给其他已注册的成员                                    |
| 新消息提醒       | 其他频道来消息有未读红点；页面在后台时标题显示未读数 + 提示音                     |
| 深色现代界面      | 左侧栏布局、彩色头像、连续消息合并、日期分隔条、窄屏自适应                        |

## 二、快速开始（3 分钟）

### 环境要求

- **Python 3.10 或更高版本**（[下载地址](https://www.python.org/downloads/)）
  - Windows 安装时**务必勾选 `Add Python to PATH`**，否则命令行找不到 python
- 不需要数据库软件（用 Python 自带的 SQLite）
- 不需要联网（依赖装完之后可以完全离线运行）

### Windows 用户

双击 **`start.bat`** 就行。它会自己完成"创建虚拟环境 → 装依赖 → 启动服务"三步，第一次会慢一点（约 1 分钟），之后双击秒开。

启动成功后，命令行窗口会打印类似这些内容：

```
本机访问地址：http://127.0.0.1:8000
局域网访问地址：http://10.194.233.79:8000
```

**把这个窗口保持开着**，关掉它聊天室就停了。

### Linux / macOS 用户

```bash
cd 项目目录
chmod +x start.sh
./start.sh
```

### 想手动装也行（三个系统通用）

```bash
python -m venv venv                  # Windows 用 python，Linux/macOS 用 python3
venv\Scripts\pip install -r requirements.txt   # Windows
# ./venv/bin/pip install -r requirements.txt    # Linux / macOS
venv\Scripts\python server.py        # Windows
# ./venv/bin/python server.py                   # Linux / macOS
```

装依赖很慢或失败时，加国内镜像：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 三、让别人也能用

服务启动后，**运行服务的那台电脑就是"服务器"**。

1. 查运行服务那台电脑的内网 IP（服务启动时窗口里会打印）：
   - Windows：命令行输入 `ipconfig`，找**无线网卡**下面的 `IPv4 地址`
   - Linux / macOS：终端输入 `ip addr` 或 `ifconfig`
2. 把网址发给同局域网的人，格式是：`http://那台电脑的IP:8000`  
   例如 `http://10.194.233.79:8000`
3. 对方用浏览器打开 → 点「注册」→ 起账号名和密码 → 开始聊天。**对方什么都不用装。**

### 想给对方一个"双击即开"的入口文件（Windows）

双击 **`make_url.py`**（或命令行 `python make_url.py`），会在 `发给同学\` 文件夹里生成一个 `.url` 文件。

把它发给对方（**建议先打成 zip**，免得被聊天软件拦截），对方解压双击，就会用他自己电脑上的浏览器打开聊天室。

> 注意：这个文件里写的是**当前的内网 IP**。如果 WiFi 重连后 IP 变了，重新运行一次 `make_url.py` 生成新文件再发一次。

### 想做成桌面 App

- 用 Edge 或 Chrome 打开 `http://127.0.0.1:8000`，地址栏右侧会出现「安装」图标，点一下就能装成独立窗口的桌面应用。
- 或者把 `open-app.bat` 发送到桌面快捷方式（右键 → 发送到 → 桌面快捷方式），双击它会**自动判断服务有没有运行，没运行就先启动再打开窗口**。
- ⚠️ 只有在 `127.0.0.1` / `localhost` 上打开才会出现「安装」按钮（浏览器规定：明文 http 的局域网地址不允许安装为应用）。

## 四、使用说明

1. **第一个注册的账号自动成为管理员**（昵称旁有「管理员」标识），拥有清空频道、转让管理员的权限。
2. 想加频道：编辑 `server.py` 顶部这一行，改完重启服务即可：
   ```python
   ROOMS = ["闲聊", "工作"]      # 想加频道直接往这里加名字
   ```
3. 想换端口（比如 8000 被别的软件占了），两种方式：
   - 改 `server.py` 顶部的 `PORT = 8000`；
   - 或者**不改代码**，启动时设环境变量：
     - Windows：`set CHAT_PORT=8080` 然后双击 `start.bat`
     - Linux / macOS：`CHAT_PORT=8080 ./start.sh`
4. 消息长度、历史条数、密码最短长度等配置都集中在 `server.py` 顶部的「集中配置」区。

## 五、常见问题

**Q：别人打不开网址？**  
按顺序排查：

1. **服务还开着吗？** 运行服务那台电脑不能关机 / 休眠 / 合盖，黑窗口不能关。
2. **防火墙拦了吗？**（最常见）Windows 首次运行常会弹防火墙提示，点「允许访问」。  
   若已经错过弹窗，用**管理员身份**打开命令行执行一次：
   ```
   netsh advfirewall firewall add rule name="ChatRoom 8000" dir=in action=allow protocol=TCP localport=8000
   ```
3. **IP 对不对？** 重新 `ipconfig` 核对；注意不要填成 VPN、虚拟机、热点虚拟网卡的地址（一般是 `10.x` / `192.168.x` / `172.16~31.x`）。
4. **网络通不通？** 让对方 `ping 运行服务的那台电脑的IP`，ping 不通说明网络层就不通（例如校园 WiFi 开启了「客户端隔离」，这种情况只能换手机热点或换有线网）。

**Q：提示端口被占用？（报错里有 `10048`）**  
说明这台电脑上的 8000 端口已经被别的程序（或另一个聊天室实例）占了。两种改法：

- 改 `server.py` 顶部的 `PORT`；
- 或者启动时设环境变量：`set CHAT_PORT=8080`（Windows）／`CHAT_PORT=8080 ./start.sh`（Linux / macOS）。

**Q：多个人各跑了一个聊天室，会冲突吗？**  
不会，**每个聊天室是完全独立的**：账号不通用、消息不互通、在线成员互不可见——因为数据存在各自目录下自己的 `chat.db` 里。同学用哪个 IP 就进哪个聊天室，唯一要留意的是**别进错房间**（比如局域网里同时有两个，先确认自己进的是哪一个）。

想在**同一台电脑**上同时跑两个实例也可以，只要给它们设不同的端口（例如一个 8000、一个 8100）。

**Q：页面一直显示"断开连接"？**  
多半是**直接双击打开了 `index.html` 文件**（地址栏是 `file://...`）。那样没有后端，肯定连不上。必须用 `http://IP:8000` 访问。

**Q：重启电脑后要做什么？**  
Windows 不会自动启动服务。开机后双击 `start.bat`（或桌面快捷方式）即可；所有人需要重新登录一次（除非之前勾选过记住登录）。聊天记录和账号**不会丢**。

**Q：IP 变了怎么办？**  
服务启动时会打印新地址，用新地址访问即可；给对方的 `.url` 文件要重新生成。校园网的 IP 通常几小时到几天才变一次。

**Q：聊天记录存在哪？能删吗？**  
存在项目目录的 `chat.db` 文件里。删掉这个文件就等于清空所有账号和聊天记录（服务下次启动会重新建一个空的）。管理员也可以在网页上清空当前频道。

## 六、目录结构

```
lan-chatroom/
├── server.py          # 后端：托管页面 + 登录注册 + WebSocket 广播 + SQLite 读写
├── index.html         # 前端：整个聊天界面（原生 JS，无框架）
├── requirements.txt   # Python 依赖（3 个）
├── start.bat          # Windows 一键启动（自动建环境装依赖）
├── start.sh           # Linux / macOS 一键启动
├── open-app.bat       # Windows：没启动就先启动，然后打开聊天窗口
├── make_url.py        # 生成发给别人的 .url 入口文件（Windows）
├── manifest.json      # PWA 安装清单（配合浏览器"安装为应用"）
├── sw.js              # Service Worker（只缓存静态资源）
├── icon-192.png       # 应用图标
├── icon-512.png       # 应用图标（大）
├── chatroom.ico       # Windows 图标
├── LICENSE            # MIT 许可证
└── chat.db            # 聊天数据库（首次运行自动生成，已设为不上传）
```

## 七、技术栈

| 层    | 选型                                            |
| ---- | --------------------------------------------- |
| 后端   | Python 3.10+ / FastAPI / Uvicorn              |
| 实时通信 | WebSocket（广播用 asyncio 异步发送，多人并发不阻塞）           |
| 数据库  | SQLite（Python 自带，零配置；全部使用参数化查询防 SQL 注入）       |
| 前端   | 单个 HTML 文件 + 原生 JavaScript + CSS 变量，无框架、无构建工具 |

安全性说明：密码 PBKDF2-SHA256 加盐哈希；前端渲染一律用 `textContent`，不拼接 HTML；SQL 全部参数化；WebSocket 连接必须携带有效凭证，否则拒绝。
